## 4. 待回答问题

### Q1：几个整数？格式串是什么？

> 看 `valid_u32_fields` 前面的 `mov $?,%esi`，以及 `sscanf` 后的 `cmp $?,%eax`。
> 格式串地址是 `0x403186`。

答：2, `%u %u`

### Q2：两个输入分别存在哪？

> 看 `4024c2` 和 `4024c6` 两条 `lea`：`rcx` 是 `sscanf` 第 4 个参数，`rdx` 是第 3 个。
> 第 3 个参数对应格式串里第 1 个 `%u`。

| 第几个数 | 栈上地址 | 传给 `sscanf` 的参数 |
| -------- | -------- | ---------------------- |
| 1        | rbp-0x1c | rdx                    |
| 2        | rbp-0x18 | rcx                    |

### Q3：p5_traverse 的参数与副作用

> 调用时 `rdi` 是 challenge，`rsi` 是 `rbp-0x14` 的地址。
> 在函数里，`rsi` 被复制到 `r8`，之后有一条 `mov %esi,(%r8)`。
>
> 问：第 2 个参数是做什么用的？`p5_traverse` 的返回值又和哪个输入比较？

答：输出槽指针

p5_traverse的返回值和第一个输入比较

### Q4：节点结构

> `p5_traverse` 里对节点指针 `rdx` 的访问有三处：
>
> ```asm
> 402457:	mov    0x4(%rdx),%esi
> 40245c:	xor    (%rdx),%eax
> 402474:	mov    0x8(%rdx),%rdx
> ```
>
> 请填出：

| 字段 | 偏移 | 宽度 | 依据                                                                      |
| ---- | ---- | ---- | ------------------------------------------------------------------------- |
| a    | 0    | 4    | 目的寄存器eax是32位，且是异或进来的结果                                   |
| b    | 4    | 4    | 目的寄存器esi是32位，且该值被相加、被输出，是个整数                       |
| next | 8    | 8    | 目的寄存器rdx是64位，且被搬进rdx后，rdx后来又被当作地址解引用，所以是指针 |

节点总共占多少字节？

答：4+4+8=16

next 是 8 字节指针需要 8 字节对齐，16 是 8 的倍数，且 next 正好从偏移 8 占到 16

### Q5：第一个节点从哪来？

> ```asm
> 40243d:	and    $0x7,%eax
> 402444:	mov    0x405b60(,%rax,8),%rdx
> ```
>
> 这是一个"基址 + 变址 × 8"的寻址方式，说明 `0x405b60` 处放着一组 8 字节的元素。
> 用 `nm -S bomb | grep p5_heads` 看它的名字和大小。
>
> 问：这张表一共几项？用什么做下标？

答：

输出：`0000000000405b60 0000000000000040 r p5_heads`

第一列是表在内存中的起始地址，第二列是表占多少字节，40代表64个byte，r是符号类型。

整张表一共64字节，每项8字节，所以一共8项。

用challenge的低三位作下表，每一项指向一条链的头结点

### Q6：初始累加值

> 从 `402453` 到 `402468`，`eax` 被连续异或、相加了好几次。
> 请按顺序写出它最后等于什么（用 challenge 和节点字段表示）。

答：

`((((challenge >> 6) ^(challenge >> 32)) ^ a) ^ 0x2511) + b`

### Q7：还要走几个节点

> ```asm
> 40245e:	mov    %ecx,%edi
> 40246a:	and    $0x3,%edi
> 40246d:	je     402489
> ```
>
> `ecx` 是 `challenge >> 3`。`and $0x3` 之后取值范围是多少？
> 循环里 `ecx` 从 1 开始数，`cmp %ecx,%edi` + `jae` 决定什么时候停。
>
> 问：从第一个节点之后，还要再走几个节点？

答：

令`t = (challenge >> 3) & 3`

edi取值范围0~3，还要再走t个

### Q9：两个输入的完整表达式

> 第 1 个输入等于 `p5_traverse` 的返回值；第 2 个输入等于它写到输出槽里的值。
> 把 Q5~Q8 串起来，写出完整的计算过程。

答：

```C++

typedef struct p5_node {
    u32 a;
    u32 b;
    struct p5_node *next;
} Node;
int t = (challenge >> 3) & 3;
Node *node = (Node*)(*(0x405b60 + 8 * (challenge & 7)));
u32 result = ((((challenge >> 6) ^(challenge >> 32)) ^ node->a) ^ 0x2511) + node->b;
for (int i = 0; i < t; i++) {
  node = node->next;
  result ^= node->a;
  result += node->b;
}
values[0] = result;
values[1] = node->b;
count = 2;
```
